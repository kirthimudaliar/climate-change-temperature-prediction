# 🌍 Climate Change Impact Analysis & Future Temperature Prediction

## 📌 Project Overview

This project focuses on analyzing the impact of environmental and socio-economic factors on climate change and predicting average temperature using Machine Learning.

The project uses historical climate and environmental data and builds multiple regression models to predict temperature.

---

## 🎯 Project Objective

The main objective of this project is to:

- Analyze important factors affecting temperature.
- Understand relationships between climate and environmental variables.
- Build Machine Learning models for temperature prediction.
- Compare different regression algorithms.
- Develop an interactive application for temperature prediction.

## 🤖 Machine Learning Algorithms

Three Machine Learning regression algorithms were implemented:

### 1. Linear Regression

Linear Regression is used to understand the linear relationship between input variables and average temperature.

### 2. Decision Tree Regression

Decision Tree Regression makes predictions by splitting the data into different conditions and learning patterns from the dataset.

### 3. Random Forest Regression

Random Forest Regression combines multiple decision trees to produce a more robust and accurate prediction.

The models were compared to identify the better-performing approach for temperature prediction.
